## Demo script

1. Open Overview and point out the explicit DEMO / SYNTHETIC label.
2. Open Device Explorer and search for `demo-00`.
3. Open a device record and show the API-backed telemetry dialog.
4. Open Model Lab and explain that empty state means no research report has been generated.
5. Run `make research-full`, refresh the dashboard, and compare the persisted model results.
6. Open MLOps Center to inspect registry and runtime state.
7. Finish with `GET /docs`, `/health/ready`, and `/metrics`.

## Screenshot policy

Screenshots must be captured from a running instance after the API and model artifacts are available. Do not commit placeholder screenshots or generated charts that were not produced by the application.
